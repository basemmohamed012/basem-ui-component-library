# Basem UI Component Library

A modern and reusable React UI component library built with **React, Tailwind CSS, and Storybook**.

The project was developed as part of the **Codveda Advanced Front-End Development tasks**, with a focus on reusable components, clean UI, responsive layouts, accessibility, and component documentation.

## 🚀 Live Demo

**Live Website:**
https://basem-ui-component-library.vercel.app/

**GitHub Repository:**
https://github.com/basemmohamed012/basem-ui-component-library

## 📚 Storybook

Storybook is used to develop, test, and document the reusable components independently.

Run Storybook locally:

```bash
npm run storybook
```

Then open:

```text
http://localhost:6006
```

## 🧩 Components

The library currently includes:

### Button

Reusable button with multiple variants and sizes.

* Primary
* Secondary
* Outline
* Danger
* Small
* Medium
* Large
* Disabled

### Input

Flexible form input with:

* Labels
* Placeholder support
* Required state
* Validation errors
* Disabled state
* Accessible error messages

### Card

Flexible content container supporting:

* Title
* Description
* Images
* Custom content
* Footer actions

### Badge

Status and category indicators with multiple variants:

* Default
* Success
* Warning
* Danger
* Info

### Modal

Reusable dialog component with:

* Controlled open/close state
* Custom content
* Close button
* Accessible dialog attributes
* Responsive layout

### Alert

Feedback component supporting:

* Info
* Success
* Warning
* Danger
* Dismissible alerts

### Spinner

Animated loading indicator with:

* Multiple sizes
* Multiple variants
* Accessible loading label
* Reduced-motion support

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/basemmohamed012/basem-ui-component-library.git
```

Navigate to the project:

```bash
cd basem-ui-component-library
```

Install dependencies:

```bash
npm install
```

## 💻 Development

Start the React development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

## 📖 Storybook Development

Start Storybook:

```bash
npm run storybook
```

Build Storybook for production:

```bash
npm run build-storybook
```

## 🏗️ Production Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
